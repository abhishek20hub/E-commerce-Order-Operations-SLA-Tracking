# E-commerce Order Operations & SLA Tracking

## Project Overview

A practical Operations Associate project created to simulate day-to-day e-commerce order processing and operational tracking using Microsoft Excel.

## Objective

To track orders, monitor processing status, identify issues, manage pending cases, monitor SLA and TAT, and prepare operational reports.

## Tools Used

- Microsoft Excel

## Operations Activities

- Order processing and tracking
- Data entry and handling
- Data verification and validation
- SOP compliance
- SLA and TAT monitoring
- Pending and backlog tracking
- Productivity reporting
- MIS reporting
- Exception and issue handling
- Escalation management
- Root Cause Analysis (RCA)
- Process improvement
- Quality checks
- Professional email communication
- Stakeholder communication

## Project Workflow

Raw Order Data  
→ Operations Tracker  
→ Order Processing  
→ Issue & Exception Handling  
→ SLA/TAT Tracking  
→ Pending/Backlog Tracking  
→ Productivity & MIS Reporting  
→ RCA & Process Improvement  
→ Quality Check

## Key Outcomes

- Tracked order status, payment status, priority, and operational actions.
- Monitored SLA and TAT and identified SLA breaches.
- Managed pending cases and documented escalation details.
- Prepared productivity and MIS reports for operational monitoring.
- Performed RCA for an SLA breach and documented corrective action.
- Created an SOP and performed final quality checks.

## Project Type

Practical Operations Simulation / Personal Project
